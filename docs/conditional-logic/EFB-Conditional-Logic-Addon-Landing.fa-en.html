ابتدا صفحه Add-ons را بررسی کنید و مطمئن شوید Conditional Logic Addon فعال است. سپس یک فرم را در فرم ساز باز کنید و وارد Form Settings شوید. اگر پلن Free باشد یا addon فعال نباشد، ممکن است به جای rule builder پنجره ارتقا یا قفل نمایش داده شود.

آیا فیلد hidden اگر required باشد جلوی ارسال فرم را می گیرد؟

در منطق فعلی افزونه، فیلد یا مرحله ای که با rule مخفی شده باشد در validation و submission نادیده گرفته می شود. بنابراین کاربر نباید به خاطر required بودن فیلدی که در مسیر او دیده نمی شود متوقف شود.

برای فرم چندمرحله ای چه کارهایی می توان انجام داد؟

می توانید step را نمایش دهید، مخفی کنید یا کاربر را مستقیم به step مشخص منتقل کنید. این برای فرم های ثبت نام، درخواست قیمت، پشتیبانی و پرداخت بسیار کاربردی است.

آیا می توان ایمیل ها را بر اساس پاسخ کاربر به افراد مختلف فرستاد؟

بله. در تب Notifications قانون شرطی می سازید و گیرنده، subject و template را مشخص می کنید. برای مثال Sales به تیم فروش، Billing به مالی و Technical به پشتیبانی فنی ارسال می شود.

آیا می توان بعد از ارسال فرم کاربر را به صفحه متفاوت برد؟

بله. در تب Confirmation می توانید بر اساس شرط، پیام اختصاصی نمایش دهید یا کاربر را به URL مشخص ریدایرکت کنید. همچنین می توانید از توکن های فیلد در URL مقصد استفاده کنید.

Test Mode چه فایده ای دارد؟

قبل از انتشار فرم، مقدار نمونه وارد می کنید و می بینید کدام قوانین Matched، Not matched یا Skipped می شوند. این کار خطاهای مسیرهای پیچیده را قبل از دریافت submission واقعی پیدا می کند.

English Guide

Easy Form Builder Conditional Logic Addon: Activation and Admin Guide

This section is written for WordPress admins, webmasters, agencies, and site owners who want to use Conditional Logic without touching code.

What It Does

Conditional Logic lets your form react to the visitor's answers. You can show or hide fields, make fields required, skip steps, route users, send targeted emails, show different confirmations, redirect users, and trigger webhooks only when the right condition is matched.

How to Activate It

  1. Open the WordPress dashboard.
  2. Go to Easy Form Builder.
  3. Open Add-ons.
  4. Find Conditional Logic Addon.
  5. Install, download, or activate it if your package allows it.
  6. Edit a form, open Form Settings, then open Conditional Logic.

How to Create a Rule

  1. Add the fields you need in the form builder.
  2. Open Conditional Logic.
  3. Select the correct tab: Fields, Notifications, Confirmation, or Webhook.
  4. Click Add.
  5. Build the IF condition by selecting source, field, operator, and value.
  6. Build the THEN action and choose the target.
  7. Save the rule and test it with Test Mode.

Popular Use Cases

  • Show Company Name only when Customer Type is Business.
  • Require Order Number only for support requests.
  • Hide the payment step for free registrations.
  • Send high-value leads to a sales manager.
  • Redirect Pro plan users to a booking page.
  • Send CRM webhooks only for qualified leads.

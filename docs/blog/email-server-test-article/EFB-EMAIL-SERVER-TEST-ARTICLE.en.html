Why WordPress contact forms fail to send email

By default, WordPress sends email through PHP's own mail() function, not an authenticated delivery service. On shared hosting, this commonly means:

  • The host blocks or throttles PHP's mail() function.
  • The email sends but, lacking authentication, lands straight in spam or gets rejected.
  • The domain's SPF record is missing or incorrect.
  • DKIM isn't configured, so receiving servers can't verify the sender.
  • No DMARC policy exists.
  • The "From" address configured in the form builder doesn't match the sender address configured in the SMTP plugin.
  • Greylisting or spam filters on the receiving server hold the message temporarily.

None of this is visible from inside wp-admin — WordPress usually reports the email as "sent" even when it never arrives. The only reliable way to know is to send a real email and confirm real delivery from an independent server, which is exactly what Easy Form Builder's email test does.

The built-in Email Server Test in Easy Form Builder

Easy Form Builder includes a Check Email Server test right inside its settings. It sends a real email through your site's current server configuration and, with the help of its partner service WhiteStudio, verifies whether it actually arrived. Results appear live, step by step, in the same panel — along with a deliverability score and a full report emailed to your site admin.

⚠️
Before you start: the From Address in Easy Form Builder settings must match the sender address configured in your SMTP plugin. If they don't match, email won't be delivered even if everything else is set up correctly. The default is admin@example.com — change it to a real address on your domain before testing.

How to run the test

  1. Log in to your WordPress dashboard.
  2. In the sidebar, open Easy Form Builder.
  3. Click Panel to open the main panel.
  4. In the top navigation, click Settings.
  5. Open the Email Settings tab.
  6. Make sure Admin Email holds a valid address — that's where the full report is sent.
  7. Click "Check Email Server."

The fix: install WP Mail SMTP

If the test failed or your score is below 70, the most reliable fix is installing WP Mail SMTP. It replaces WordPress's default mail() function with an authenticated SMTP connection that receiving servers can verify and trust.

  1. Go to Plugins → Add New.
  2. Search for WP Mail SMTP.
  3. Click Install Now, then Activate.
  4. Follow the setup wizard to configure it.

If your host doesn't provide dedicated SMTP access, use a transactional email service instead — SendGrid, Mailgun, Gmail/Google Workspace, Amazon SES, Brevo, or Postmark all work with WP Mail SMTP.

⚠️
Remember: after configuring WP Mail SMTP, go back to Easy Form Builder → Panel → Settings → Email Settings and make sure From Address matches the SMTP sender. Then click Check Email Server again.

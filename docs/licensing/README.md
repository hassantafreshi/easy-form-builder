# Pro Activation for Easy Form Builder — Complete End-User Guide

> [Docs index](../README.md)

Stop letting a support ticket be the only way people learn there's no separate "Activate" button. This guide covers **where the Easy Form Builder activation code actually goes** (Settings → General → Activation Code, saved with the page-wide Save button), how to get that code from the pricing page, the real Free / Free Plus / Pro tier split (Free Plus needs no code at all), the Plan Management block and plan-selection overlay, domain binding and what happens on migration, license expiration and renewal, and every "Pro required" message the plugin shows — verified directly against the licensing code in `includes/functions.php` and `includes/admin/class-Emsfb-admin.php`, available in four languages:

- Persian (فارسی) — [آموزش کامل فعال‌سازی نسخه ویژه (Pro) فرم ساز آسان](EFB-Pro-Activation-Complete-Guide.fa.md)
- English — [How to Activate the Pro Version of Easy Form Builder: Complete Guide](EFB-Pro-Activation-Complete-Guide.en.md)
- Arabic (العربية) — [الدليل الكامل لتفعيل النسخة الاحترافية (Pro) من منشئ النموذج السهل](EFB-Pro-Activation-Complete-Guide.ar.md)
- German (Deutsch) — [So aktivierst du die Pro-Version von Easy Form Builder: Der komplette Leitfaden](EFB-Pro-Activation-Complete-Guide.de.md)

Each guide covers the same ground in full: getting the code from the pricing page, entering it under Settings → General, the Plan Management / Change Plan overlay (Free, Free Plus, Pro), how domain-hash validation works and what happens after a migration, the weekly re-check and the offline validation path for Farsi-locale sites, expiration banners and renewal, every "Pro Version Required" / "Free Plus or Pro" prompt in the product, a common-errors table, a pre-activation checklist, an FAQ section, ready-to-publish `FAQPage` JSON-LD structured data for SEO, and editorial notes for publishing the article on a website.

This folder replaces ad hoc, screenshot-based activation write-ups (like the one previously published at whitestudio.team/document/how-to-activate-pro-version-easy-form-builder-plugin/) with a version checked against the plugin's actual UI strings and save flow, so it won't go stale the next time a label changes.

Frequently asked questions

Is there a separate "Activate" button?

No. The activation code saves together with every other setting on the General tab — paste it in, then click the page's single Save button.

How many sites can one license cover?

Exactly one domain. The code is bound to that domain, and every subdomain is billed and licensed on its own.

What's the real difference between Free Plus and Pro?

Free Plus is free and already unlocks advanced fields, capped conditional logic, CSV export, and the weekly deliverability report. Pro removes those caps and adds every official add-on — Stripe, PayPal, SMS, Telegram, Auto-Populate, Google Sheets.

My code worked before — why does it show Free now?

Almost always a domain change since the code was issued: a migration, a protocol change, or a move from staging to a live URL. The license is bound to the exact original domain string.

Will Pro stop working if the license server is unreachable?

No — the plugin falls back to validating your code against the domain hash embedded in it, so an already-active license keeps working.

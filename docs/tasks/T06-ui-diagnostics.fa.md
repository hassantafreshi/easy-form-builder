# T06 — تشخیص محدود خرابی رابط، بدون بازطراحی گسترده

وضعیت: منتظر T02. [قیود مشترک](README.fa.md).

فایل‌های شروع: `public/assets/js/core-efb.js`، `request-health-efb.js`، `includes/class-Emsfb-public.php`، `includes/class-Emsfb-request-health.php`.

## دامنهٔ کوچک

ابتدا چرخهٔ init فرم و dependencyهای ضروری مشخص شود. قرارداد محدود شروع/آماده‌شدن و خطای مرتبط با asset افزونه طراحی شود. معماری Shadow DOM، بازنویسی کامل CSS و جمع‌آوری همهٔ خطاهای صفحه در این تسک نیست.

## پذیرش پیش از توسعهٔ بیشتر

بارگذاری دیرهنگام، فرم شرطی و مرحلهٔ پنهان خطا شمرده نشوند. گزارش فقط دستهٔ allowlist و نسخهٔ asset داشته باشد؛ URL کامل، متن exception/DOM، ورودی، فایل و توکن ذخیره نشوند. بارگذاری‌نشدن خود پایشگر قابل گزارش تضمینی نیست. گزارش نشانهٔ خرابی باشد، نه ادعای شناسایی افزونهٔ مقصر. هیچ reload یا ارسال خودکار برای «ترمیم» انجام نشود.

تست هدفمند: dependency مفقود، init تکراری، فرم مخفی معتبر و چند فرم در یک صفحه. اگر پایش مستقل به تغییر قرارداد گزارش نیاز داشت، بخش A قرارداد و بخش B اتصال مرورگر جدا اجرا شوند.

تحویل: هنوز پیاده نشده. اقدام بعدی: مشخص‌کردن نقطهٔ معتبر پایان init و امکان false positive.

## Features 💡

You don't need any coding skills to use Easy Form Builder. Simply drag and drop your layouts into order to easily create unlimited custom multistep forms. A unique Confirmation code ( tracking ID) allows you to connect any submission to an individual request.

Features:

### Core Features

#### Form Builder & Creation
- **Drag & Drop Form Builder** - Visual interface to create forms without coding
- **Create Unlimited Forms** - No limits on the number of forms
- **Multi-Step Forms** - Divide long forms into multiple steps for better user experience
- **Mobile-Friendly Forms** - Responsive forms that work perfectly on all devices
- **Build on Any Device** - Create forms using smartphones, tablets, or desktop computers
- **Private/Public Forms** - Control form access with public or restricted-access options
- **WCAG (ADA) Compliant** - Accessible forms for individuals with disabilities
- **No Coding Required** - All features accessible without programming knowledge

#### Form Responses & Management
- **Form Entry & Message Management Dashboard** - Centralized dashboard to manage all submissions
- **Email Notifications** - Automatic email alerts when forms are submitted
- **Custom Email Templates** - Free built-in visual editor for branded WordPress form email notifications
- **Confirmation Code (Tracking ID)** - Unique identifiers for each submission
- **Confirmation Code Style** - Choose from 7 code styles with locale-aware characters supporting 55+ languages and scripts (Arabic, Persian, Hindi, Chinese, Japanese, Korean, Cyrillic, and more)
- **CSV & PDF Export** - Download form responses in CSV or PDF formats
- **Message Status Management** - Mark messages as Open or Closed
- **Admin Replies** - Reply to form submissions directly from WordPress dashboard
- **File Attachments in Replies** - Attach files when responding to form submissions
- **Entry Search & Filtering** - Find submissions by form or confirmation code
- **Bulk Actions** - Select all and manage multiple messages at once

#### Form Types & Use Cases
- Contact forms for inquiries
- Support and feedback forms with message tracking
- Survey and poll forms with result visualization
- Payment forms (Stripe & PayPal)
- Login (sign-in) forms for WordPress users
- Registration (sign-up) forms for new users
- File upload forms
- Subscription and newsletter signup forms
- Offline forms (collect data without internet connection)

#### Advanced Form Fields (+40 Field Types)
- **Text & Number Fields** - Single line, multi-line, email, number inputs
- **Selection Fields** - Dropdown, multiple select, radio buttons, checkboxes
- **File Upload** - Drag-and-drop file upload with multiple file support
- **Date Pickers** - Gregorian, Hijri (Qamari), and Jalali (Shamsi) date pickers
- **Location & Geographic Fields** - Location picker (OpenStreetMap), country, state/province, city dropdowns
- **Signature Field** - E-signature capture for agreements and authorization
- **Advanced Fields** - Rating stars, 5-point scale, Net Promoter Score (NPS), Yes/No questions, switch/toggle, range slider
- **International Telephone Input** - Country-aware formatted phone number input
- **Image Picker Field** - Select from image cards for visual choices
- **Link & Title Fields** - Add custom headings and links within forms

#### Survey & Poll Forms
- Rating star fields for satisfaction surveys
- 5-point scale questions for detailed feedback
- Net Promoter Score (NPS) fields for loyalty measurement
- Yes/No question fields for simple choices
- Survey result visualization with pie charts
- Export survey responses to CSV format

#### Payment Forms & Integration
- **Stripe Payment Fields** - Secure payment collection through Stripe
- **PayPal Integration** - PayPal payment forms and processing
- **Custom Payment Forms** - Build flexible payment forms with custom pricing
- **Donation Forms** - Accept donations with customizable amounts
- **Booking & Service Payments** - Payment collection for services and booking confirmations
- **Payment Field Options** - Single select, multi-select, dropdown, and custom pricing fields

#### Security & Spam Protection
- **Google reCAPTCHA v2** - Reduce spam and automated bot submissions
- **Shield Security silentCAPTCHA** - Invisible bot and spam protection
- **Server & Client-Side Validation** - Comprehensive form input validation
- **Data Ownership** - All submissions stored locally on your WordPress site (no external services by default)
- **Secure File Handling** - Safe file upload and management

#### Email & Communication
- **Email Notification System** - Automatic emails triggered on form submission
- **Custom Email Templates** - Free custom email notification templates with a built-in visual editor
- **Customizable Messages** - Full control over email content and layout
- **User & Admin Notifications** - Send emails to users, admins, or custom recipients
- **Instant Reply System** - Direct messaging from the WordPress dashboard
- **File Attachments** - Include files in email replies

#### Integrations & Add-ons
- **SMS Notifications** - Send SMS text messages on form submission (via WSMS plugin)
- **Telegram Bot Integration** - Real-time Telegram updates and admin notifications
- **Stripe Add-on** - Extended payment processing and workflows
- **PayPal Add-on** - Full PayPal payment integration
- **Autofill Add-on** - Auto-complete form fields from CSV data or external APIs
- **Offline Forms Add-on** - Collect data without active internet connection
- **Hijri Date Picker Add-on** - Islamic (Qamari) calendar support
- **Jalali Date Picker Add-on** - Persian (Shamsi) calendar support
- **Shield Security Integration** - silentCAPTCHA for invisible bot protection

#### Localization & Accessibility
- **RTL Language Support** - Right-to-left language compatibility for Persian, Arabic, Hebrew
- **Easy Localization** - Translate to any language with full multi-language support
- **Community Translations** - Contribute translations on WordPress.org
- **WCAG Compliance** - Accessible to users with disabilities

#### Administration & Management
- **Mobile-Friendly Admin Panel** - Manage forms on any device
- **Intuitive Dashboard** - User-friendly interface for form management
- **Form Builder Simplicity** - Intuitive form creation with drag-and-drop
- **Entry Search** - Find submissions by form name or confirmation code
- **Delete & Edit Entries** - Full control over form submission management
- **Status Tracking** - Open/Closed status for submission tracking
- **Activity Monitor** - Track and view form submission activities

#### Developer & Additional Features
- **Bootstrap Support** - Seamless Bootstrap framework integration
- **Page Builder Compatibility** - Works with Elementor, Divi, Gutenberg, Visual Composer, WPBakery
- **Unlimited Customization** - Full control over form appearance and behavior
- **Responsive Design** - Mobile-first responsive layouts
- **Performance Optimized** - Compatible with popular caching plugins
- **Form Submission Tracking** - Monitor all submissions with detailed logs
- **Confirmation Code Finder** - Easy lookup tool for form submission references
- **Data Export Options** - Multiple export formats (CSV, PDF)
- **Entry Management** - Organize and manage hundreds of submissions
- **Professional Support** - Access to documentation and community support

It also protects your notification budget by stopping suspicious entries from consuming email, SMS, Telegram, webhook, or Google Sheets quota, supports an IP allowlist and blocklist, and keeps privacy-aware security logs that store hashed identifiers instead of raw IP addresses. It starts in Monitor-only mode, so you can review real traffic before turning on blocking
